Order-on-the-go
Collaboration repo for Full Stack Developer MERN Stack Internship Project

🚀 Project Overview
Order-on-the-go is a full-fledged food ordering platform built with the MERN stack. It allows users to explore restaurants, browse menus, add items to the cart, and place orders with a seamless user experience.

This project is a part of a real-time internship focused on building scalable, production-ready applications using modern web technologies.

🛠 Tech Stack
Frontend: React (Vite), Tailwind CSS
Backend: Node.js, Express.js
Database: MongoDB (optional for future)
Other: JSON APIs (currently used for mock data)
📂 Features
🔐 User authentication (login/signup)
🍔 Menu listing & product filtering
🛒 Add to cart with quantity control
💵 Price calculation & cart updates
📱 Responsive UI
🌐 External API/mock data integration
